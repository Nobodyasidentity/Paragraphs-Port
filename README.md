# Paragraphs port
> Lets you type characters like §

based on <a href="https://github.com/yiyuyan/ParagraphsReborn" target="_blank">ParagraphsReborn</a>.  
for older Minecraft versions, use <a href="https://modrinth.com/mod/paragraphs" target="_blank">Paragraphs</a> by fungoza/hacker1337.  

Minecraft mod that allows you to write Section sign (§) in any text fields  
May be useful when you paste item NBT in command block or item editor mods
