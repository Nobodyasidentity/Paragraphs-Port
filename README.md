# Paragraphs port
> Lets you type characters like §

based on [ParagraphsReborn](https://github.com/yiyuyan/ParagraphsReborn).  
for older Minecraft versions, use [Paragraphs](https://modrinth.com/mod/paragraphs) by fungoza/hacker1337.  

Minecraft mod that allows you to write Section sign (§) in any text fields  
May be useful when you paste item NBT in command block or item editor mods
